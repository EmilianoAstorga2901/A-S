# Prisma

Prototipo mobile-first de una billetera digital con foco en inversiones, creado con React y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

La interfaz está optimizada para un viewport de 390 × 844 px y también se adapta a pantallas mayores.

## Descarga directa para Visual Studio Code

Si la descarga general del repositorio aparece vacía, descargá el archivo
[`downloads/prisma-wallet.zip`](downloads/prisma-wallet.zip) desde GitHub usando
**Download raw file**. Después descomprimilo y abrí la carpeta resultante en
Visual Studio Code mediante **Archivo → Abrir carpeta**.

El ZIP incluye `package.json`, `index.html`, `README.md` y todo el directorio
`src/`. Una vez abierto, ejecutá `npm install` y `npm run dev` en la terminal de
Visual Studio Code.
