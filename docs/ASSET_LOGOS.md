# Identidades visuales de activos

## Regla de presentación

1. Si el proveedor de mercado entrega un logo, se muestra primero.
2. Si no existe o la imagen falla, Prisma utiliza el SVG real guardado en `public/assets/logos` para las marcas registradas en V6.
3. Si el instrumento no tiene una marca corporativa —por ejemplo un bono soberano, una conversión MEP o un producto ficticio— se muestra un ícono neutral de su categoría. Nunca se fabrican siglas con un color aleatorio.
